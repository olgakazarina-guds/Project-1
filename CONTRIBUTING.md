# Contributing to Pixel Defender

Welcome to the Digitalis Protocol. This project is part of a university assignment, and we welcome Peer Reviews!

## Peer Assessment Guidelines
As per the project brief:
1. **Be Honest & Encouraging:** Provide constructive feedback on the code and UX.
2. **Respectful Communication:** Do not use derogative language or offensive jokes.
3. **Yellowdig Integration:** Please post your reviews on Yellowdig using the "Project 1 - Review" topic.

## How to Report Bugs
If the game crashes (e.g., a NullPointerException), please open an "Issue" on GitHub with a screenshot of the console error.
